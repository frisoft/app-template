# Rename the app

Rules live in `AGENTS.md`. Do this **once, as its own commit, before any domain
code exists** — renaming a populated workspace is noisier for no benefit.

## Principle

There are **two independent names**, and only one of them is load-bearing:

1. The **package prefix** `app-` on the four workspace crates.
2. The **binary name** `app` (`[[bin]] name` in `crates/cli/Cargo.toml`).

The library *import* names (`domain`, `application`, `infrastructure`) are
deliberately decoupled from the package names by the `package = "..."` mapping in
the root `[workspace.dependencies]`. Rename the packages freely and **not a single
`use` statement changes** — that is what keeps this task small and safe. Do not
"fix" the left-hand `name =` keys in that block; they are the import names.

## Steps

1. Pick both names first and write them down. Example: packages `shop-*`, binary
   `shop`.
2. Root `Cargo.toml`, `[workspace.dependencies]`: update the three
   `package = "app-*"` values. Leave the `domain` / `application` /
   `infrastructure` keys alone.
3. Each crate manifest, `name = "app-*"`:
   - `crates/domain/Cargo.toml`
   - `crates/application/Cargo.toml`
   - `crates/infrastructure/Cargo.toml`
   - `crates/cli/Cargo.toml`
4. `crates/cli/Cargo.toml`: update `[[bin]] name = "app"` (independently of the
   crate name).
5. `crates/cli/src/main.rs`: update the `println!("app-template: …")` string and
   the comment that names the `app` binary.
6. `Makefile`: update `cargo run -p app-cli` to the new CLI package name.
7. Docs, so the repo does not describe itself falsely:
   - `AGENTS.md` — the repository map (§4) and the `make run` comment (§6).
   - `README.md` — the layout block and the `cargo run -p app-cli` line.
8. Do **not** hand-edit `Cargo.lock`; let `cargo check` rewrite it.

## Explicitly not touched

- `flake.nix`, `.envrc`, `.github/workflows/ci.yaml` — all name-agnostic by
  design (CI runs `make` targets only).
- The checkout directory (`app-template`) is not baked in anywhere except
  generated `.direnv/` noise; renaming the folder is unrelated and optional.

## Checklist

- [ ] Both names chosen before starting; done as a single standalone commit.
- [ ] `package = "app-*"` updated in the root workspace deps; import names
      untouched.
- [ ] Crate `name` fields and the CLI `[[bin]] name` updated.
- [ ] `Makefile`, `AGENTS.md` (§4, §6) and `README.md` updated.
- [ ] `grep -rn 'app-cli\|app-domain\|app-application\|app-infrastructure'`
      returns nothing except lines you intentionally kept.
- [ ] `Cargo.lock` regenerated by Cargo, not edited by hand.
- [ ] `make check` passes and `cargo run -p <new-cli-crate>` prints the new name.

## Note

`[workspace.package] authors` / `repository` are placeholders too — replace them
while you are here, but they are unrelated to the rename itself.
